# nathanohare.github.io

Keeps the old web app address working after the repository was renamed from Chem-Illustrator to
Chemweave. Anything under `https://nathanohare.github.io/Chem-Illustrator/` is sent to the same
place under `https://nathanohare.github.io/Chemweave/`, with its `?query` and `#hash` kept.

The app itself is published from [nathanohare/Chemweave](https://github.com/nathanohare/Chemweave).
Do not create a repository named Chem-Illustrator: that would stop GitHub's redirects from the old
repository address, which installed copies of the app use to find updates.
